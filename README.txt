NEXORA AUTOMOTIVE
Premium automotive website + Supabase admin panel

START HERE:
1. Read SETUP.md.
2. Run supabase/schema.sql in your Supabase SQL Editor.
3. Add your Supabase URL and anon/public key in js/config.js.
4. Set the WhatsApp number in js/config.js.
5. Run a local server: python -m http.server 5500
6. Open http://localhost:5500
7. Admin page: http://localhost:5500/admin.html

The public site includes sample inventory for preview. Admin login and live inventory management require Supabase setup.
Do not put a service_role key in js/config.js.
